idlescape

The web shell's design library. Every class on this page is real and shared with the app; the source is web/src/styles/ and the helpers in web/src/ui/. RuneLite's sidebar is the reference point: dark, dense, one orange accent, and nothing decorative that does not carry information.

Rules of thumb: orange marks the current thing or the main action, and nothing else. Controls are 27px tall, with 22, 25 and 29px for row actions, card actions and panel-width calls to action. Labels are sentence case. Motion only answers an action.

Colour

Colours are read straight: var(--panel), or an rgba() the bundle already declares, like var(--hairline). Sections 1 and 8 of styles/tokens.css are the whole palette and this is all of it; styles/tokens.test.ts pins every value against the vendored bundle, and pins that a token declared there has a swatch here.

Icons

Eleven drawn glyphs and no twelfth. Each is 16 by 16 on a 1.5px stroke, drawn in currentColor, so a glyph takes the colour of whatever it sits in and no call site ever sets one on the svg. This is the whole icon set, and every strip button, panel header and plugin row on this page draws from it. The settings gear on a plugin row was the last font glyph left in the shell; Task 20 rebuilt the Plugins panel and it draws config now, so the set below is the only glyph source the shell has.

The names are display names, not plugin ids: automation is the plugin tasks and claude is connect. A manifest naming a glyph that does not exist draws plugins rather than an empty button.

Size

The second argument scales the box only. The viewBox never moves, so a bigger glyph is the same drawing with a proportionally finer stroke.

Navigation

Two families and one rule between them: the thing you are on is marked in orange and nothing else is. The icon strip is a vertical tab list down the right edge, generated from the plugin manifest; the character tabs are four slots across the top, always four. Every glyph is one of the eleven drawn icons above.

Icon strip

Eleven buttons in three groups, separated by hairlines, with Plugins and Configuration pushed to the bottom. The open panel takes the card ground, the accent glyph and the 2px rail. A live run paints a 6px corner dot on the button that owns it. The spacer that makes that bottom group rides on the first button in it, which is Plugins.

Character tabs

Four slots, always: the character you are on, the ones you have made, the open slot, and the one that is not built yet. Only the online clock is mono; the words beside it are not.

Co-pilot bar

Forty-two pixels of chrome between the character tabs and the canvas, in all five presented states. It answers two questions at once, which is why it reads two sources: is Claude paired, and is anything running. The dot and the 2px rule beneath carry the state, the clock is mono and tabular, and the second row says what the run is doing on the left and what it is earning on the right. Every bar below is drawn by the real renderer, so nothing here can drift from the frame.

Overlays, windows and menus

Everything that floats speaks one language: a black scrim, a 1px tone-tinted border, a 3px radius, bold mono and a 2px backdrop blur. Pills float over the game canvas, windows over the whole stage, and a menu is the same surface at menu size. Transparency and blur live here and never inside a panel.
