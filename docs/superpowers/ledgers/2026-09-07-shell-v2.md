## Traps recorded

- `new URL('../x.css', import.meta.url)` handed to `node:fs` throws under jsdom. Use `node:path`.
- **jsdom weighs no specificity and evaluates no media query.** It resolves competing declarations by
  source order, so a rule that must win has to be written later, a `@media` block is reachable only
  through `cascade.harness.ts`'s `declarationsInMedia`, and a specificity claim is a Playwright claim.
  Its cssstyle also **drops a shorthand carrying a `var()`**, which is why `.card-rail-*` and
  `.card-lift:hover` ship as three `border-left-*` longhands.
- **`new KeyboardEvent('keydown', { key: 'Escape' })` is not cancelable**, so `preventDefault()` is a
  no-op and `defaultPrevented` never becomes true. A panic-key case built on it passes against a
  window that swallows the key.
- **A listener left bound but inert has no behavioural signature.** Both teardown holes this entry
  found, the trace window then the co-pilot bar, needed a by-reference assertion, the module guarding
  on state the disposer also clears.
- **`page.mouse.click` outside the viewport is a silent no-op** that looks exactly like a click the
  client ignored; it cost one session a bisect. `canvasClick` now scrolls and throws, and
  `openBankWindow` waits out `popIn` for the same class of failure.
- **A CSS grid `auto` row takes its height from cell CONTENT**, so `aspect-ratio` on a cell in a
  scrolling pane draws overlapping rows; and `1fr` is `minmax(auto, 1fr)`, so a nowrap tile widens its
  own column. Use `minmax(0, 1fr)`.
- **`scripts/verify.ps1` run through the Bash tool dies mid-gate**, twice here, at steps 2 and 3: the
  tool's wrapper owns the pipe and the run goes with it. Run it detached from PowerShell with
  `Start-Process -RedirectStandardOutput`, which also writes UTF-8 rather than `Tee-Object`'s UTF-16.
  The tell is a log that stops mid-step with no error line under it.
- **A screenshot tolerance expressed as a ratio scales with the section**, giving the tallest sections
  the loosest guard; absolute `maxDiffPixels` against a measured zero-diff floor is the right shape.
