idlescape

A static, simplified copy of the rendered game frame and every side panel. No build step, no server, no JavaScript beyond the panel switcher below. The CSS is the real web/src/styles/*.css, concatenated verbatim; the markup mirrors what each panel module actually produces at runtime. Companion to panel-ui-brief.md.

Goal for the rebuild: usability and joy before OSRS nostalgia — familiar to an OSRS player, but adopting modern conventions wherever they genuinely improve usability.

1 · The frame

1440×900 desktop layout. Click a strip icon on the right to swap the panel. The game canvas is a placeholder here — in the real thing it is a same-origin /play.html iframe running the 2004 client at 789×532.
