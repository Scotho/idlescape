One button, five variants: default grey, primary orange-gradient (the one main action per surface), danger, outline (quiet row actions), link.

```jsx
<Button variant="primary">Run a script</Button>
<Button size="xs" variant="outline">Revoke</Button>
```

Primary carries an orange glow; never place two primaries side by side. xs is for row-level actions (Trace, Delete), lg for panel-width CTAs.
