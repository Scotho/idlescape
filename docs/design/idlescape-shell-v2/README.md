# Handoff: idlescape shell redesign + design system

## Overview
A redesign of the idlescape panel UI (the shell around the 2004 game canvas), plus the
design system codifying it. Headline changes vs. the shipped `feat/platform-shell` UI:

- A persistent **co-pilot bar** above the canvas (the "what is Claude doing" surface, in all five
  run states), replacing the run banner that only existed during a run.
- Side panel widened to **280px** (was 210), with a pinnable XP tracker and a **pop-out trace
  window** over the stage.
- **Automation** panel (renamed from Tasks) with internal **My tasks / Marketplace** tabs;
  Marketplace removed from the strip.
- New **Events** panel: cross-character feed filterable by character (segmented), type (chips:
  XP/Loot/Levels/Runs/Claude/Bank), and skill (select).
- **Characters merged into Account** (one panel; strip loses a button).
- Emoji strip replaced with a drawn 16×16 geometric SVG icon set.
- Modern polish: gradient cards, 6–10px radii, hairline borders, orange focus rings, motion
  (shimmer XP bars, animated run rule, fadeUp panel switches, OSRS-style xp drops).
- All digits move from Pixelify Sans to **bold ui-monospace** (digit legibility — a pixel "5"
  reads as "S"); Pixelify remains only for the wordmark and canvas captions.
- HUD (HP/Pray/Run) restyled into the same black-scrim pill language as the other canvas overlays.
- Live **online timer** on the active character tab (mono, `1:29:07`), replacing the word "online".

## About the design files
Everything in this bundle is a **design reference built in HTML** — prototypes showing intended
look and behavior, not production code. The task is to recreate them in the existing `web/`
environment: **Vite + vanilla TS, no framework** — panels built with `h()` (`web/src/ui/el.ts`)
or `innerHTML` templates, token-driven plain CSS in `web/src/styles/*.css`, files under 400 lines.

The bundled `components/*.jsx` are React **only because the design-system tooling requires it**.
Do NOT introduce React. Each maps to a static equivalent (see "Component library, statically").

## Fidelity
**High-fidelity.** Colors, sizes, spacing, and copy are final; recreate pixel-perfectly.
`Idlescape Shell v2.dc.html` is the source of truth for every literal value (all styles are inline).

## Implementing the design system in `web/`

1. **Tokens** — replace/extend `web/src/styles/tokens.css` with the values in `tokens/colors.css`,
   `typography.css`, `spacing.css`, `motion.css` (bundled here). Keep the existing RGB-triplet
   convention if `rgba(var(--x),a)` call sites demand it; the alpha variants used are enumerated
   in `tokens/colors.css` (e.g. `--accent-tint: rgba(255,152,31,.15)`).
2. **Base** — `tokens/base.css` holds the button/input transition defaults, focus ring, scrollbar
   and selection styles; fold into `web/src/styles/base.css`.
3. **Component classes** — express each component below as a CSS class family (this is also the
   moment to retire the `.p-*` aliases; the new classes supersede both dialects).
4. **Keyframes** — `pulse, shimmer, barflow, floatUp, fadeUp, popIn, bob, stepPulse` (in
   `tokens/motion.css`), all disabled under `prefers-reduced-motion`.

## Component library, statically
One CSS class family per component + (where stateful) a tiny `h()` builder in `web/src/ui/`.
Specs (exact values) live in `components/<group>/<Name>.jsx` + `.d.ts` + `.prompt.md`:

| Badge (accent/ok/warn/error/info/neutral, optional dot) | `.badge` + tone modifiers |
| Tag | `.tag` |
| StatusDot (tone, pulse, glow) | `.dot` + `.dot-ok/-accent/-warn/-error`, `.dot-pulse`, `.dot-glow` |

| SectionLabel | `.section-label` |

| Input / Select / Textarea / Checkbox | `.input`, `.select`, `.textarea` (+`.code`), native checkbox with `accent-color` |
| Segmented | `.seg` container + `.seg-btn` (+`.active`); builder `segmented(options, value, onChange)` |
| Card (rail, gradient) | `.card` + `.card-rail-<tone>` + `.card-hero` |
| KV | `.kv` row (`.kv-label`, `.kv-value`, `.num`) |
| Meter (pct, tone, shimmer) | `.meter` track + `.meter-fill` (+`.shimmer`, `.meter-hp/-prayer/-run`) |

Maintain it statically: every new panel composes these classes; no per-panel one-off styles.
The five `components/**/*.card.html` files are visual regression references per family.

## Interactions & behavior
- Strip click → open panel (persist to `localStorage['cs.panel']` — keep the `cs.` prefix).
- Pause/Resume/Stop drive the run state everywhere at once (bar, run card, strip dot, pills).
- Paused auto-resume countdown ticks per second (settings default 5000ms).
- Esc = panic key contract unchanged (incl. iframe re-dispatch).
- Panel switch: `fadeUp .18s`; windows: `popIn .18s`; buttons: `.13s ease` + 1px hover lift;
  primary hover widens the orange glow. All off under reduced motion.
- Timers: online timer ticks 1s (mono h:mm:ss); elapsed ticks while running; xp counters tick
  every ~3s during a run (drives xp drop + logs/xp counters).
- Pin (XP panel header) → compact pinned card above the panel header; × unpins.

## State
Per character: run state (unpaired/standby/running/paused/stuck), elapsed, session xp/loot,
events list, online seconds. Per account: bank. UI: open panel id, Automation tab, event filters
(character/types/skill), pinned tracker, trace/bank window open.

## Assets
- No logo: wordmark is Pixelify Sans 16px `#ff981f` with `text-shadow: 0 0 12px rgba(255,152,31,.35)`.
- Icon glyphs: 11 inline SVG paths in `components/core/Icon.jsx` (16×16, stroke 1.5, currentColor).

- Bank item icons: game cache (production); wiki hot-links in the mock are placeholders.

## Load-bearing constraints (from the original brief — keep them)
- `[data-panel="<id>"]`, `#side-panel`, `#panel-body`, `[data-task-run]`, `[data-bank-slot]`,
  `#bank-capacity` etc. drive 21 Playwright specs + ~791 unit tests. The Characters→Account merge
  and Tasks→Automation rename touch panel ids/titles — flag and migrate deliberately.
- `localStorage` keys keep the `cs.` prefix; renames silently reset player state.
- Strip stays generated from the plugin manifest; panels re-mount on every open; `unmount()`
  releases timers. Everything but the bank is per-character.
- ARIA: strip tablist + arrow keys, `aria-live` panel, labels on icon-only buttons, one focus ring.
