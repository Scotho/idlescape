# Connecting Claude

## What you need

- An account on idlescape (a guest account is fine).
- [Claude Code](https://claude.com/claude-code) installed.

## Steps

1. Open idlescape at `{{ORIGIN}}`.
2. Press **Connect to Claude**.
3. Copy the pairing link shown in the connect card.
4. Paste it into a Claude Code session and say **"connect to this"**.
5. Wait for the status line to read **Paired**.

## What Claude can and cannot do

Once paired, Claude can observe your session and answer questions about it, and can act in
the game only when you ask it to. You stay in control at all times — Claude never plays on
its own, and every pairing can be revoked instantly from the Claude Connection panel.

## Managing connections

The **Claude Connection** panel (in the icon strip, under the chat icon) lists every paired
Claude session for your account: its label, when it was created, and when it was last seen.
Press **Revoke** on any row to disconnect that session immediately.

## Troubleshooting

- **"This link has expired"** — pairing links are single-use and expire after 15 minutes.
  Press **Connect to Claude** again for a fresh one.
- **"gateway not deployed yet"** — the pairing itself succeeded, but the game-connection
  gateway isn't live yet. This is expected during early access; try again later.
- **A session I didn't expect is paired** — revoke it from the Claude Connection panel, then
  mint a fresh pairing link.
- **My guest account's progress is gone** — guest progress lives only in the browser that
  created it. If you cleared site data or switched devices, that guest character can't be
  recovered. Create an account with an email next time to avoid this.
